# Данные

В папке лежат только файлы, которые реально используются в проекте.

## processed

`vacancies_final.csv` — основной очищенный датасет. В нем 3149 вакансий аналитиков после удаления дублей.

`vacancies_for_model_final.csv` — датасет для модели. В нем 693 вакансии с зарплатой в рублях после фильтрации явного выброса.

Сырые JSON-выгрузки из API hh.ru не добавлены в репозиторий, потому что они большие и нужны в основном как рабочий промежуточный слой.

## model

`metrics/model_metrics.csv` — метрики качества модели.

`predictions/sample_predictions.csv` — несколько примеров прогнозов.

`metadata/model_metadata.json` — параметры последнего обучения.

Сами `.joblib`-модели не добавлены. Их можно получить заново через:

```bash
cd salary_model_project
python3 train_salary_model.py
```
