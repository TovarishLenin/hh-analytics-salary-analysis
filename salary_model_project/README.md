# Модель зарплатной вилки

В этой папке лежит код ML-прототипа для оценки зарплатной вилки аналитика.

Файлы:

| Файл | Назначение |
|---|---|
| `model_config.py` | признаки, пути и варианты пользовательского выбора |
| `train_salary_model.py` | обучение модели и сохранение метрик |
| `predict_salary_cli.py` | консольный прототип для прогноза |

Модель использует `RandomForestRegressor`. Отдельно обучаются две модели:

- для `salary_from`;
- для `salary_to`.

Обучить модель:

```bash
python3 train_salary_model.py
```

Запустить прототип:

```bash
python3 predict_salary_cli.py
```

Во время прогноза пользователь выбирает роль, опыт, городскую группу, формат работы и навыки. На выходе получается примерная зарплатная вилка в рублях.

Модель учебная, поэтому результат лучше воспринимать как ориентир по данным hh.ru, а не как точный прогноз зарплаты.
