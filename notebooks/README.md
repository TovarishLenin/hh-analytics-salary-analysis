# Ноутбуки и графики

В папке лежат два основных ноутбука:

| Файл | Что внутри |
|---|---|
| `eda_vacancies.ipynb` | предварительный анализ вакансий, зарплат, ролей, городов, опыта и навыков |
| `clustering_and_hypotheses.ipynb` | кластеризация и проверка гипотез о факторах зарплаты |

Готовые графики лежат в папках:

```text
figures/
figures_3_2/
```

Ноутбуки читают данные из:

```text
../data/processed/vacancies_for_model_final.csv
```

Если запускать ноутбуки из папки `notebooks/`, пути должны работать без дополнительных настроек.
