# Анализ вакансий аналитиков и прогнозирование зарплат по данным hh.ru

Это учебный pet-проект на основе курсовой работы второго курса.  
В проекте я собрал вакансии аналитиков с hh.ru, подготовил данные, посмотрел распределение зарплат, сравнил роли и сделал простой прототип ML-модели для оценки зарплатной вилки.

Проект не претендует на промышленный сервис прогноза зарплаты. Главная идея была разобраться, какие признаки вакансии связаны с зарплатой аналитика: опыт, регион, формат работы, роль и навыки.

## Что сделано

- собраны вакансии аналитиков через API hh.ru;
- удалены дубли и подготовлен итоговый CSV;
- выделены направления аналитики: Business, System, BI/DWH, Data, Product, DS/ML;
- рассчитан `salary_mid`;
- построены графики по зарплатам, ролям, городам, опыту и навыкам;
- проверены основные гипотезы о факторах зарплаты;
- обучен прототип модели `RandomForestRegressor`;
- сделан консольный скрипт для примерной оценки зарплатной вилки.

## Признаки

В анализе и модели используются:

- профессиональная роль вакансии;
- региональная группа;
- требуемый опыт;
- формат работы;
- тип занятости;
- нижняя и верхняя граница зарплаты;
- наличие навыков: SQL, Python, Excel, Power BI, DWH, ETL, ML, BPMN, UML, API, Jira и другие.

## Модель

Для прогноза используется `RandomForestRegressor`.

Обучаются две модели:

- `model_from` прогнозирует нижнюю границу зарплаты;
- `model_to` прогнозирует верхнюю границу зарплаты.

Чтобы модель меньше переобучалась на небольшой выборке, у деревьев ограничена глубина и увеличено минимальное число объектов в листе.

Сохраненные `.joblib`-модели не лежат в репозитории. Их можно получить заново после запуска обучения.

Метрики на тестовой выборке:

| Цель | MAE | RMSE | R2 |
|---|---:|---:|---:|
| `salary_from` | 43 598.91 | 55 345.66 | 0.4643 |
| `salary_to` | 57 179.43 | 80 142.18 | 0.3802 |

Подробные выводы и гипотезы вынесены в [RESULTS.md](RESULTS.md).

## Как запустить

Установить зависимости:

```bash
python3 -m pip install -r requirements.txt
```

Разделить данные на train/test:

```bash
cd hh_parser_project
python3 split_model_data.py
```

Обучить модель:

```bash
cd ../salary_model_project
python3 train_salary_model.py
```

Запустить консольный прототип:

```bash
python3 predict_salary_cli.py
```

## Ограничения

- Не все вакансии на hh.ru содержат зарплату.
- В модели учитываются только зарплаты в рублях.
- Не учитывается различие gross/net.
- Навыки выделяются по тексту вакансии, поэтому возможны неточности.
- Модель учебная: ее можно использовать для демонстрации подхода, но не как точный калькулятор зарплаты.
