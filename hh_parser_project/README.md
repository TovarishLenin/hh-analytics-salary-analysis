# Парсер hh.ru

В этой папке лежит код для сбора вакансий через API hh.ru и подготовки CSV.

Основной файл:

```text
collect_hh_vacancies.py
```

Он собирает вакансии аналитиков, получает детали вакансий, очищает описание от HTML, выделяет роли, зарплату, городскую группу и признаки навыков.

Для быстрого теста:

```bash
python3 collect_hh_vacancies.py --max-pages 1 --max-areas 1 --max-details 10
```

Для разделения модельного датасета на train/test:

```bash
python3 split_model_data.py
```

После запуска создаются или обновляются файлы в общей папке `data/`.

Важно: полную выгрузку с hh.ru не всегда удобно повторять часто, потому что API может ограничивать частые запросы. Поэтому в репозитории уже лежат подготовленные CSV-файлы, которые используются в анализе и модели.
